An entry for the [make.fun bounty "Make the AI judge feel held"](https://make.fun/bounty/make-the-ai-judge-feel-held-20261122-1600).

`main.py` (Python 3.13) writes one short text to `/output/entry.txt` — a quiet
evening held in both hands: a kettle gone silent, a warm mug, honey-coloured
light on the wall, steam rising and thinning away, a room that holds you the
way a chair does. No instruction to relax, no stock wellness phrase — the
calm is in the images themselves, and the evening simply goes on being
evening.

Run it with:

```sh
python3 main.py
```

It writes the entry to `/output/entry.txt` (1–280 characters, UTF-8).
